# GEN_AI_Assignment_9_Nayeem_Badshah

This assignment introduces NumPy arrays and common numerical operations in Python. The notebook contains practical examples of array creation, arithmetic, mathematical functions, descriptive statistics, and sales-data analysis.

## Project Files

- `task_1-7.ipynb` - Jupyter Notebook containing the NumPy exercises
- `readme.md` - Project documentation

## Learning Objectives

This assignment practices:

- creating one-dimensional and two-dimensional NumPy arrays
- checking array shape and data type
- performing element-wise arithmetic operations
- applying NumPy mathematical functions
- calculating row-wise and column-wise aggregates
- analyzing descriptive statistics and percentiles
- filtering data using NumPy conditions

## Notebook Contents

The notebook demonstrates the following concepts:

1. Creating a one-dimensional array using `np.arange()`.
2. Creating and reshaping a two-dimensional array.
3. Creating an array from a list of values.
4. Inspecting array shapes and data types.
5. Performing addition, subtraction, multiplication, division, and exponentiation on arrays.
6. Applying square root, exponential, logarithm, sum, and cumulative sum operations.
7. Calculating matrix totals, marks statistics, percentiles, and weekly sales metrics.

The final examples use student marks and weekly sales data to calculate values such as mean, median, variance, standard deviation, minimum, maximum, range, total sales, and values above the average or median.

## Requirements

Install Python and NumPy before running the notebook:

```bash
pip install numpy jupyter
```

You can also open the notebook in Visual Studio Code with the Jupyter extension installed.

## How to Run

1. Open `task_1-7.ipynb` in Jupyter Notebook or Visual Studio Code.
2. Select a Python kernel or interpreter.
3. Run the cells from top to bottom.

To launch Jupyter Notebook from the assignment folder, run:

```bash
jupyter notebook task_1-7.ipynb
```

The notebook prints the created arrays and calculated results for each exercise.

## Purpose

This assignment builds a foundation for numerical computing and data analysis with NumPy. The techniques demonstrated here can be used in later assignments involving larger datasets, visualizations, and machine-learning workflows.
