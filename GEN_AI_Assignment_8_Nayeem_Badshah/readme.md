# GEN_AI_Assignment_8_Nayeem_Badshah

This project is a beginner-level Streamlit assignment that demonstrates how to build simple interactive web apps using Python. It focuses on user input, data display, basic calculations, and UI layout design.

## Project Overview

The assignment includes several small Streamlit applications that showcase different features:

- `app_basic.py` - A basic greeting app that takes the user's name and displays a personalized message.
- `app_dashboard.py` - A simple sales dashboard with a month selector and bar chart.
- `app_discount.py` - A discount calculator that calculates the final price after applying a discount.
- `app_product_form.py` - A sidebar-based product form for collecting product details.

## Learning Objectives

This assignment helps practice:

- creating interactive Python web apps with Streamlit
- using text inputs, sliders, number inputs, and buttons
- displaying metrics and charts in the UI
- handling basic validation and business logic
- designing simple dashboards and forms

## Folder Structure

- `app_basic.py` - Basic welcome page with greeting functionality
- `app_dashboard.py` - Sales dashboard with monthly sales data
- `app_discount.py` - Discount calculation logic and UI
- `app_product_form.py` - Product form created in the sidebar
- `readme.md` - Project documentation

## Requirements

Before running the project, make sure Python and Streamlit are installed.

Install Streamlit using:

```bash
pip install streamlit
```

## How to Run

Open a terminal in the project folder and run any one of the following commands:

```bash
streamlit run app_basic.py
```

```bash
streamlit run app_dashboard.py
```

```bash
streamlit run app_discount.py
```

```bash
streamlit run app_product_form.py
```

Each command will launch the corresponding app in the browser.

## App Descriptions

### 1. Basic App
The greeting app allows users to enter their name and click a button to see a personalized greeting.

### 2. Sales Dashboard
This app shows sample monthly sales data and uses a bar chart to present the results visually. The user can choose a month from a dropdown list.

### 3. Discount Calculator
This app accepts an original price and a discount percentage. It calculates the discounted value and displays the result with validation for negative inputs.

### 4. Product Form
This app provides a sidebar form where users can enter a product name, product category, price, and submit product details.

## Purpose

This assignment introduces the basics of Streamlit app development and helps build a strong foundation for creating more advanced interactive data-driven applications in the future.
