# GEN AI — Assignment 1 (Tasks from notebook)

**Project:** Python data-structure exercises using lists, tuples, sets, and dictionaries.

- **Notebook:** [Nayeem_GEN_AI_task_1-4.ipynb](Nayeem_GEN_AI_task_1-4.ipynb)

**Requirements:**
- **Python:** 3.8+
- **Jupyter:** use `jupyter lab` or `jupyter notebook`

**Quick setup:**
```bash
pip install jupyterlab
# or
pip install notebook
```

**How to run:**
- Open the notebook linked above and run the cells sequentially.

**Implemented Tasks (from the notebook):**
- **Task 1 — Product Collections (Lists & Tuples):** creates `products` (list), `sample_product` (tuple); demonstrates indexing, appending, and converting tuple→list→tuple to update the price.
- **Task 2 — Categories (Sets):** builds `categories_set` from a categories list; demonstrates adding categories, duplicate handling, membership checks, and counting unique categories.
- **Task 3 — Product Pricing (Dictionaries):** constructs `price_dict` with product prices; shows adding/updating/removing products and computes the average price plus min/max priced products.
- **Task 4 — Combined Operations:** creates a `catalog` list of `(product_name, price, category)` tuples, groups products into `category_to_products`, and prints the products in the largest category. In the current data, `Electronics` is the largest category.

**Notes:**
- The notebook contains Tasks 1–4. Run all cells from top to bottom so that the variables used by later tasks are initialized.
